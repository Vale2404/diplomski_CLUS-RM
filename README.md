This code is a modified version of the CLUS-RM algorithm from the repository https://github.com/matmih/CLUS-RM-library and an extension of the implementation from the master's thesis "Algorithmic and Implementation Optimizations of the CLUS-RM Supplementing Forest" (A. Rosanda, 2025), https://urn.nsk.hr/urn:nbn:hr:217:254535, which builds on the master's thesis "Algorithmic and Implementation Optimizations of the CLUS-RM Redescription Mining Approach" (I. Jukić, 2022), https://dabar.srce.hr/islandora/object/pmf%3A10483. It was created as part of the master's thesis "Investigation of Initialization Procedures for the CLUS-RM Algorithm" at the Faculty of Science, Department of Mathematics, University of Zagreb, in 2026. The thesis advisor is Associate Professor Matej Mihelčić, Ph.D.
